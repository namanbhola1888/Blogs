# Blog

A clean, reading platform for essays and articles.

## What's Inside

- **Comfortable Reading:** Generous line spacing, clean typography, reading time estimates, and an automatic table of contents for long articles.
- **Light & Dark Mode:** Warm, easy-to-read themes for daytime and nighttime reading.
- **Search & Categories:** Filter stories by topic or search directly by keyword.
- **Reading List:** Bookmark articles to save and read later.
- **Adjustable Text Size:** Scale font sizes up or down directly on any article page.
- **Built-in Editor:** A dedicated studio to write, edit, and publish articles, categories, and author profiles.

## Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **CMS:** Sanity Studio
